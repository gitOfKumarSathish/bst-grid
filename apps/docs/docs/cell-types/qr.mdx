# `qr`

inline-SVG QR code (byte mode, v1–10).

![The qr cell rendered in a Bst-Table grid](/img/cell-qr.png)

<BstSandbox example="cell-qr" />

## Guide

### When to use it

A scannable QR code generated from a value — a URL, SKU, or token.

### How it works

Reads a `string` and renders a dependency-free inline-SVG QR (byte mode, versions 1–10). Editing
swaps in a text input and the code re-renders live.

### Options

- `cellMeta.ecLevel` — error-correction level `'L'` | `'M'` (default) | `'Q'` | `'H'`.
- `cellMeta.size`, `cellMeta.margin`.

## At a glance

| | |
| --- | --- |

## Use it

```tsx no-check
const columns: BstTableColumn<Row>[] = [
  { id: 'x', accessorKey: 'x', header: 'X', meta: { type: 'qr', /* cellMeta below */ } },
]
```

## `cellMeta` options

**`qr`**
| `cellMeta` | Type | Effect |
| --- | --- | --- |
| `ecLevel` | `'L' \| 'M' \| 'Q' \| 'H'` | Error-correction level. Default `'M'`. |
| `size` | `number` | Rendered px. Default `88`. |
| `margin` | `number` | Quiet-zone modules. Default `2`. |
