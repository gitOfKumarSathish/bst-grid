# `boolean`

check ✓ / muted dash.

![The boolean cell rendered in a Bst-Table grid](/img/cell-boolean.png)

<BstSandbox example="cell-boolean" />

## Guide

### When to use it

A yes/no flag — active, archived, verified, in-stock.

### How it works

Renders a check (✓) for `true` and a muted dash for `false`. Editing toggles a checkbox. Stored as
a `boolean`.

## At a glance

| Editable | ✅ checkbox |
