# `hyperlink`

anchor.

![The hyperlink cell rendered in a Bst-Table grid](/img/cell-hyperlink.png)

<BstSandbox example="cell-hyperlink" />

## At a glance

| | |
| --- | --- |
| Renders | anchor |
| Value shape | `string or { href, label }` |
| Editable | ✅ url input |
| Key `cellMeta` | target |

## Use it

```tsx
const columns: BstTableColumn<Row>[] = [
  { id: 'x', accessorKey: 'x', header: 'X', meta: { type: 'hyperlink', /* cellMeta below */ } },
]
```

## `cellMeta` options

**`hyperlink`**
| `cellMeta` | Type | Effect |
| --- | --- | --- |
| `target` | `string` | Anchor `target`. Default `'_blank'`. |
