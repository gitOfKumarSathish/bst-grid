# Column pinning

Prop `enableColumnPinning` — engine behaviour, default `false`.

## Overview

| | |
| --- | --- |
| Layer | `enable*` (engine, resolved in `useBstTable`) |
| Type | `boolean` |
| Default | `false` |
| Status | ✅ done (Phase 3) |
| Settings sheet | Columns |

## Enable it

```tsx
<BstTableMui
  data={rows}
  columns={columns}
  enableColumnPinning
/>
```

> Swap `BstTableMui` for `BstTableShadcn` (and the CSS import) for the shadcn skin — same props.
