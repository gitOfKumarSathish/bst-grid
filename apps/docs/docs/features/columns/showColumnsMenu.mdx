# Columns menu

Prop `showColumnsMenu` — adapter chrome, default `true`.

## Guide

### When to use it

On by default — the toolbar menu that hosts the per-column controls.

### How it works

Renders the **Columns** button and its menu, the home for show / hide (`enableHiding`), pin
(`enableColumnPinning`), reorder (`enableColumnOrdering`), copy-column and edit-lock controls.

### Gotchas

- Turning it off hides those controls; the underlying behaviours still work via keyboard and the
  settings sheet.
- It's chrome — same menu in both skins (Radix `DropdownMenu` for shadcn, MUI `Menu` for MUI).

## Enable it

```tsx no-check
<BstTableMui
  data={rows}
  columns={columns}
  enableHiding          // chrome is a no-op without its behaviour flag
  showColumnsMenu
/>
```

> Swap `BstTableMui` for `BstTableShadcn` (and the CSS import) for the shadcn skin — same props.

## Behavior & interactions

- **Requires** `enableHiding` to be on — this flag is a no-op otherwise.
