# Column reordering

Prop `enableColumnOrdering` — engine behaviour, default `false`.

## Guide

### When to use it

Let users arrange columns to taste — drag a header, or use the move controls in the columns menu.

### How it works

Enables drag-to-reorder on headers plus "move left / right" in the columns menu
(`showColumnsMenu`), driving the engine's column order.

### Gotchas

- Pinned columns stay within their pinned zone; reordering happens inside each zone.
- Persist the arrangement with `gridState={{ key }}` if it should survive a reload.

## Overview

| | |
| --- | --- |
| Layer | `enable*` (engine, resolved in `useBstTable`) |
| Type | `boolean` |
| Default | `false` |
| Maps to | v9 setColumnOrder (adapter menu + header drag-drop) |
| Status | ✅ done (Phase 3) |
| Since | v0.7.0 |
| Settings sheet | Columns |

Column reordering — the adapter column menu (move left/right) **and** drag-to-reorder on the header (→ v9 `setColumnOrder`). Default: false.

## Enable it

```tsx
<BstTableMui
  data={rows}
  columns={columns}
  enableColumnOrdering
/>
```

> Swap `BstTableMui` for `BstTableShadcn` (and the CSS import) for the shadcn skin — same props.
