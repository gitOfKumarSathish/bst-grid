# Global search box

Prop `showSearch` — adapter chrome, default `true`.

## Overview

| | |
| --- | --- |
| Layer | `show*` (chrome, resolved in the adapter) |
| Type | `boolean` |
| Default | `true` |
| Status | ✅ done |

## When to use it

On by default — the global search box in the toolbar.

## How it works

Renders the search input and drives the engine's global filter.

## Gotchas

- **Requires `enableGlobalFilter`** (on by default) — the box is inert without it.
- It's toolbar chrome, so it also needs `showToolbar` to be visible.

## Enable it

```tsx
<BstTableMui
  data={rows}
  columns={columns}
  enableGlobalFilter          // chrome is a no-op without its behaviour flag
  showSearch
/>
```

> Swap `BstTableMui` for `BstTableShadcn` (and the CSS import) for the shadcn skin — same props.

## Behavior & interactions

- **Requires** `enableGlobalFilter` to be on — this flag is a no-op otherwise.
