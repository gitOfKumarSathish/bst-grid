# Display

Density, conditional formatting, overlays and status bar.

![A status bar and density controls under a grid](/img/display.png)

Display features shape **how cells look and how state is surfaced** — density, conditional
formatting, loading / error overlays and a status bar. Overlays default on (a server-wired grid
shows loading / error for free); the rest are opt-in. Conditional formatting is rule-driven and
composes with the CSS slots (`classNames` / `styles`).

| Feature | Flag | Default |
| --- | --- | --- |
| [Cell spanning (A5)](./enableCellSpanning) | `enableCellSpanning` | `false` |
| [Conditional formatting runtime toggle (K3)](./enableConditionalFormatting) | `enableConditionalFormatting` | `true` |
| [Loading / error overlays (X23)](./enableOverlays) | `enableOverlays` | `true` |
| [Density toggle](./showDensityToggle) | `showDensityToggle` | `false` |
| [Filter builder UI (E3)](./showFilterBuilder) | `showFilterBuilder` | `false` |
| [Format builder UI (K3)](./showFormatBuilder) | `showFormatBuilder` | `false` |
| [Status bar (X5)](./showStatusBar) | `showStatusBar` | `false` |
