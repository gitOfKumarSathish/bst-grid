# Cell spanning (A5)

Prop `enableCellSpanning` — engine behaviour, default `false`.

## Overview

| | |
| --- | --- |
| Layer | `enable*` (engine, resolved in `useBstTable`) |
| Type | `boolean` |
| Default | `false` |
| Status | ✅ done |
| Settings sheet | Display |

## When to use it

Merge cells that share a value — a spanning header down a category column, or a wide cell across
columns — like merged cells in a spreadsheet.

## How it works

Supports both `colSpan` and `rowSpan`. Drive it with `getCellSpan`, or set `meta.rowSpan: 'group'`
to span contiguous equal values in a column. Covered cells are skipped in render.

## Gotchas

- Row virtualization **yields** to spanning (`rowSpan` needs contiguous real rows), so spanned grids
  render un-windowed.
- `rowSpan` groups collapse automatically when a sort / filter breaks the contiguity.

## Enable it

```tsx
<BstTableMui
  data={rows}
  columns={columns}
  enableCellSpanning
/>
```

> Swap `BstTableMui` for `BstTableShadcn` (and the CSS import) for the shadcn skin — same props.

## Options

| Option | Notes |
| --- | --- |
| `getCellSpan or meta.rowSpan` | spanning is opt-in per cell; without either nothing merges |
