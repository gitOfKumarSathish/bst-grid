# Toolbar (whole)

Prop `showToolbar` — adapter chrome, default `true`.

## Guide

### When to use it

On by default — the toolbar that hosts search, the columns menu, export, settings and the rest.

### How it works

Renders the whole top toolbar. Turn it off for an ultra-minimal, chrome-free grid (the behaviours
still work via keyboard).

### Gotchas

- With it off, toolbar-hosted controls (`showSearch`, `showColumnsMenu`, `showExport`,
  `showSettings`, …) have nowhere to render.
- The Add-row bar and save bar sit **below** the table, so they survive `showToolbar={false}`.

## Overview

| | |
| --- | --- |
| Layer | `show*` (chrome, resolved in the adapter) |
| Type | `boolean` |
| Default | `true` |
| Status | ✅ done |

## Enable it

```tsx
<BstTableMui
  data={rows}
  columns={columns}
  showToolbar
/>
```

> Swap `BstTableMui` for `BstTableShadcn` (and the CSS import) for the shadcn skin — same props.

## Behavior & interactions

- The container for search, menus and buttons — turning it off hides all toolbar chrome.
- Chrome flag: it only renders its control when the matching `enable*` behaviour is on.
