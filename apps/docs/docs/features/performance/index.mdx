# Performance

Virtualization and infinite scroll for large datasets.

![A virtualized grid rendering only the visible rows](/img/performance.png)

Performance features keep large grids fast by **rendering only what's visible**. Row
virtualization (`enableVirtualization`) is the big lever; `enableColumnVirtualization` adds
horizontal windowing for very wide grids. Both default off — turn them on for thousands of rows or
hundreds of columns. Virtualization yields to master-detail, grouping, spanning and row pinning,
which need the full DOM.

| Feature | Flag | Default |
| --- | --- | --- |
| [Column virtualization](./enableColumnVirtualization) | `enableColumnVirtualization` | `false` |
| [Row virtualization](./enableVirtualization) | `enableVirtualization` | `false` |
