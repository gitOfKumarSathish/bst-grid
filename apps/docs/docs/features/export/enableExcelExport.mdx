# Excel export (X2)

Prop `enableExcelExport` — engine behaviour, default `true`.

## Overview

| | |
| --- | --- |
| Layer | `enable*` (engine, resolved in `useBstTable`) |
| Type | `boolean` |
| Default | `true` |
| Status | ✅ done |
| Settings sheet | Export |

## When to use it

Keep (or drop) the **Excel** (`.xlsx`) option in the export menu.

## How it works

A **sub-toggle of `enableExport`** (on by default). Gates `runtime.exportExcel` and the Excel menu
item; produces a real `.xlsx` (hand-built store-only ZIP + SpreadsheetML, numeric cells typed) with
**no** third-party spreadsheet library.

## Gotchas

- Only takes effect when `enableExport` is on.
- Numbers export as typed cells (not text), so downstream formulas work.

## Enable it

```tsx
<BstTableMui
  data={rows}
  columns={columns}
  enableExcelExport
/>
```

> Swap `BstTableMui` for `BstTableShadcn` (and the CSS import) for the shadcn skin — same props.

## Behavior & interactions

- **Requires** `enableExport` to be on — this flag is a no-op otherwise.
- Defaults to ON — set false to hide the Excel item / no-op `runtime.exportExcel`. Emits a real `.xlsx` (numeric cells typed).
