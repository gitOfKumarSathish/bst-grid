# CSV export (X1)

Prop `enableCsvExport` — engine behaviour, default `true`.

## Guide

### When to use it

Keep (or drop) the **CSV** option in the export menu.

### How it works

A **sub-toggle of `enableExport`** (on by default). Gates `runtime.exportCsv` and the CSV menu item;
output is RFC-4180 with a UTF-8 BOM (so Excel opens it cleanly).

### Gotchas

- Only takes effect when `enableExport` is on.
- Set it `false` to offer Excel / Print but not raw CSV.

## Overview

| | |
| --- | --- |
| Layer | `enable*` (engine, resolved in `useBstTable`) |
| Type | `boolean` |
| Default | `true` |
| Status | ✅ done |
| Settings sheet | Export |

## Enable it

```tsx
<BstTableMui
  data={rows}
  columns={columns}
  enableCsvExport
/>
```

> Swap `BstTableMui` for `BstTableShadcn` (and the CSS import) for the shadcn skin — same props.

## Behavior & interactions

- **Requires** `enableExport` to be on — this flag is a no-op otherwise.
- Defaults to ON — set false to hide the CSV item / no-op `runtime.exportCsv` while keeping Excel + Print.
