# Print (X3)

Prop `enablePrint` — engine behaviour, default `true`.

## Guide

### When to use it

Keep (or drop) the **Print** option in the export menu.

### How it works

A **sub-toggle of `enableExport`** (on by default). Gates `runtime.printTable` and the Print item;
opens a print-friendly window (with a hidden-iframe fallback).

### Gotchas

- Only takes effect when `enableExport` is on.
- It prints the current view formatted per cell type, not the raw DOM.

## Overview

| | |
| --- | --- |
| Layer | `enable*` (engine, resolved in `useBstTable`) |
| Type | `boolean` |
| Default | `true` |
| Status | ✅ done |
| Settings sheet | Export |

## Enable it

```tsx
<BstTableMui
  data={rows}
  columns={columns}
  enablePrint
/>
```

> Swap `BstTableMui` for `BstTableShadcn` (and the CSS import) for the shadcn skin — same props.

## Behavior & interactions

- **Requires** `enableExport` to be on — this flag is a no-op otherwise.
- Defaults to ON — set false to hide the Print item / no-op `runtime.printTable`.
