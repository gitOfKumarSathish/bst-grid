# Master-detail (A4)

Prop `enableExpanding` — engine behaviour, default `false`.

## Guide

### When to use it

Master-detail — click a row to reveal a full-width panel with more detail, sub-records, or a nested
table.

### How it works

Adds a leading expander column and renders your `renderDetail(row)` as a full-width row beneath the
expanded one. Control which rows can open with `getRowCanExpand`.

### Gotchas

- Row virtualization **yields** to expanding (detail rows need real DOM), so long lists with many
  open panels are heavier.
- The detail panel is your React — a nested `<BstTable>` is fine for a different column set.

## Overview

| | |
| --- | --- |
| Layer | `enable*` (engine, resolved in `useBstTable`) |
| Type | `boolean` |
| Default | `false` |
| Status | ✅ done |
| Settings sheet | Rows |

## Enable it

```tsx
<BstTableMui
  data={rows}
  columns={columns}
  enableExpanding
/>
```

> Swap `BstTableMui` for `BstTableShadcn` (and the CSS import) for the shadcn skin — same props.

## Options

| Option | Notes |
| --- | --- |
| `renderDetail` | without it an expanded row shows an empty detail panel |

## Behavior & interactions

- Optionally narrow which rows expand with `getRowCanExpand`.
