# Undo/Redo buttons

Prop `showUndoRedo` — adapter chrome, default `follows enableUndoRedo`.

## Overview

| | |
| --- | --- |
| Layer | `show*` (chrome, resolved in the adapter) |
| Type | `boolean` |
| Default | `follows enableUndoRedo` |
| Status | ✅ done (Phase 3) |

## When to use it

Add visible **Undo / Redo** buttons to the toolbar for users who don't reach for Ctrl+Z.

## How it works

`showUndoRedo` renders the two buttons and follows `enableUndoRedo`; the keyboard shortcuts work
whether or not the buttons are shown.

## Gotchas

- No-op without `enableUndoRedo`.
- The buttons disable themselves at the ends of the history stack.

## Enable it

```tsx
<BstTableMui
  data={rows}
  columns={columns}
  enableUndoRedo          // chrome is a no-op without its behaviour flag
  showUndoRedo
/>
```

> Swap `BstTableMui` for `BstTableShadcn` (and the CSS import) for the shadcn skin — same props.

## Behavior & interactions

- **Requires** `enableUndoRedo` to be on — this flag is a no-op otherwise.
