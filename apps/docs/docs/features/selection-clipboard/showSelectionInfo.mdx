# Selected-count chip

Prop `showSelectionInfo` — adapter chrome, default `follows enableRowSelection`.

## Overview

| | |
| --- | --- |
| Layer | `show*` (chrome, resolved in the adapter) |
| Type | `boolean` |
| Default | `follows enableRowSelection` |
| Status | ✅ done (Phase 3) |

## When to use it

Show how many rows are selected and offer a one-click Clear.

## How it works

Renders a `{n} selected` chip + **Clear** in the toolbar; it follows `enableRowSelection`.

## Gotchas

- No-op without `enableRowSelection`.
- It reflects **row** selection, not cell-range selection (that count lives in `showStatusBar`).

## Enable it

```tsx
<BstTableMui
  data={rows}
  columns={columns}
  enableRowSelection          // chrome is a no-op without its behaviour flag
  showSelectionInfo
/>
```

> Swap `BstTableMui` for `BstTableShadcn` (and the CSS import) for the shadcn skin — same props.

## Behavior & interactions

- **Requires** `enableRowSelection` to be on — this flag is a no-op otherwise.
