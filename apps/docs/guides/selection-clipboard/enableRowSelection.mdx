### When to use it

Let users select whole rows with checkboxes — for bulk actions (delete, export, assign) on the
chosen records.

### How it works

Renders a checkbox column (header select-all + per-row). Pair with `showSelectionInfo` for a
selected-count chip and Clear.

### Gotchas

- This is **row** selection (checkboxes), separate from **cell/range** selection
  (`enableCellSelection`) — you can run both.
- Selection targets rows by id, so pass `getRowId`.
