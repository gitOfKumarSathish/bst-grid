## When to use it

On by default — one search box that filters across all columns at once. The quickest way for a user
to find a row.

## How it works

The engine behaviour; the visible search box is the adapter's `showSearch`. Matching runs over the
rendered cell text.

## Gotchas

- The box needs **`showSearch`** (on by default) to appear — turn `enableGlobalFilter` off and the
  box does nothing.
- Distinct from **Find** (`enableFind`): global filter **removes** non-matching rows; Find
  highlights matches without hiding anything.
