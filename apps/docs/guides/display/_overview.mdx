![A status bar and density controls under a grid](/img/display.png)

Display features shape **how cells look and how state is surfaced** — density, conditional
formatting, loading / error overlays and a status bar. Overlays default on (a server-wired grid
shows loading / error for free); the rest are opt-in. Conditional formatting is rule-driven and
composes with the CSS slots (`classNames` / `styles`).
