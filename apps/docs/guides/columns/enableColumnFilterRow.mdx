### When to use it

Let users filter each column from a dedicated input **row** under the headers — the "dual filter"
layout, on top of (or instead of) the global search box.

### How it works

It adds a second header row of per-column filter inputs. It's also the **host** for the richer
filter widgets: `enableSetFilter` (a checklist of values) and `enableMultiFilter` (stacked filter
types) render into this row.

### Gotchas

- **Requires `enableColumnFilters`** — it's the UI for that engine behaviour and a no-op without it.
- It's always available in the settings sheet ("Columns"), so an end-user can switch it on themselves.
