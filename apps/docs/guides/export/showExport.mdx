## When to use it

The toolbar **Export** button and its menu.

## How it works

Renders the Export dropdown (MUI `Menu` / Radix `DropdownMenu`) with CSV / Excel / Print entries,
filtered by the per-format sub-toggles. Follows `enableExport`.

## Gotchas

- No-op without `enableExport`.
- Needs `showToolbar` to be visible; the same export actions are also on the right-click menu
  (`enableContextMenu`).
